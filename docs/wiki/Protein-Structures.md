# Protein Structures

The SAR11 Protein Structure Viewer links proteins from cultured SAR11 strains to UniProt accessions and displays available AlphaFold DB predictions.

The structure-link table has not yet been regenerated for the complete 542-genome and 4,577-orthogroup release. Until that update is complete, results reflect the preceding structure-mapping analysis and may not cover newly added or renumbered orthogroups.

## Find A Protein Match

Use the searchable table to locate a SAR11 protein, gene, orthogroup, or UniProt accession. The table reports the sequence match and amino-acid percent identity (`pident`). A value below 100% means that the SAR11 protein and UniProt sequence are not identical.

Select an accession in the table to load it into the structure viewer. Use **Full screen view** when a larger table is needed.

## View And Compare A Structure

Enter a UniProt accession and press **Update Protein Structure**. If AlphaFold DB contains a prediction for that accession, it is displayed with Mol* and the **Open Foldseek** button becomes available.

- Use **Molstar viewer Full screen view** for a larger interactive structure display.
- Use **Open Foldseek** to search for structurally similar proteins.

## Interpretation Notes

The current links were generated by sequence similarity searches against UniProt, and an accession is not necessarily an exact sequence match. Some matched accessions do not have an AlphaFold DB prediction.

UniProtKB/TrEMBL redundancy reduction can also remove or merge records that were present in an earlier release. If an older accession no longer resolves, UniParc can be used to look for its historical sequence record.

Structure predictions should be interpreted together with sequence identity, domain annotations, and model confidence rather than as experimental structures.
