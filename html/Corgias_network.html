CORGIAS Network

Explore statistically supported co-occurrence and anti-occurrence relationships among SAR11 orthogroups.

Nodes represent OGs and are colored by COG functional category. Red edges indicate co-occurrence, blue edges indicate anti-occurrence, and edge width reflects association significance as -log10(q-value).

The current 542-genome network contains 18,606 significant associations among 2,987 OGs. Enter an OG ID, set the exploration depth and minimum significance, then extract its local association network.
