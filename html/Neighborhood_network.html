Neighboring Gene Network


This is a synteny (genome neighborhood) network of orthogroups (OGs). Nodes are OGs; edges show that two OGs are frequently found near each other in the SAR11 genomes.
How to use: enter an OG ID (e.g. OG0000123) and click the Extract and show button.
Full network visualized using Cosmograph is available here, and the raw data can be downloaded as a TSV file from the Download page.
