Data access

Download

Access the genome metadata and analysis resources underlying the SAR11 Genome Atlas.

Compact, web-facing release files can be downloaded directly below. Larger reproducibility archives, including sequences, complete annotations, analysis outputs, and HMM profiles, are distributed through Zenodo.

OG representative protein sequences

One observed representative amino-acid sequence for each of the 4,577 orthogroups, provided for rapid exploratory OG assignment. Representatives were selected as the sequence with the lowest EMBOSS infoalign percent change from the OG multiple-alignment consensus. These files are the database source for the browser-based OG Search.

OG representative proteins (FAA) 1.1 MB Representative selection table (TSV) 261 KB

Orthogroup HMM profiles

The 4,577 orthogroup profile HMMs are distributed as a combined HMM library. Individual OG profiles can be retrieved from the combined file with hmmfetch.

Combined orthogroup HMM library Zenodo · 90.16 MB
Available

Orthogroup gene trees

Resolved gene trees for the 3,411 orthogroups containing at least four protein sequences, generated with the OrthoFinder 3 default workflow. Amino-acid sequences were aligned with FAMSA, approximate maximum-likelihood trees were inferred with FastTree using its -fastest option, and the trees were rooted and resolved by OrthoFinder using its hybrid species-overlap/duplication-loss coalescent model.

Resolved gene trees 9.4 MB
Available

Species phylogenies

Final dual-IQ-TREE 2 species phylogenies inferred from bac120 and from SAR11_165 HMM profiles obtained from the Meren Lab workflow. SAR11_165 is a SAR11-focused subset of an earlier 200-gene Alphaproteobacterial SCG collection. The rooted, outgroup-pruned SAR11_165 tree is the default atlas phylogeny. Original 562-tip trees retain the 20 alphaproteobacterial outgroups, and FastTree results are provided as comparison trees rather than as the final taxonomy.

Default rooted SAR11_165 IQ-TREE 2 phylogeny 24 KB Original SAR11_165 IQ-TREE 2 phylogeny with outgroups 25 KB Original bac120 IQ-TREE 2 phylogeny with outgroups 25 KB Rooted bac120 IQ-TREE phylogeny 24 KB SAR11_165 FastTree comparison phylogeny 24 KB bac120 FastTree comparison phylogeny 24 KB

High-similarity UniProt matches

High-similarity protein matches for all 542 genomes, generated against UniProtKB release 2026_01 with DIAMOND v2.1.10.164 using a minimum identity of 85% and --max-target-seqs 1. The AlphaFoldDB-linked subset additionally requires at least 80% query and subject coverage. Gene-level and orthogroup-level summary tables are provided.

Broad UniProt similarity-search results

A broader search against UniProtKB release 2026_01 was generated with DIAMOND using --max-target-seqs 10. In the combined structure-reference table, close matches require identity ≥85% with query and subject coverage ≥80%; homologous references require identity ≥30%, query and subject coverage ≥80%, and E-value ≤1e-5. The table contains the 8,057 AlphaFoldDB structure references used by the Web interface across 2,994 orthogroups.

AFDB-confirmed homologous references 1.6 MB Combined AlphaFoldDB structure-reference table (8,057 references; 2,994 OGs) 1.3 MB Complete filtered DIAMOND result Zenodo · 199.50 MB
